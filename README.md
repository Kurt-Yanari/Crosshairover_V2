# Crosshair Overlay V2 — Улучшенная версия

## Установка зависимостей
```
pip install PyQt5 keyboard pyinstaller
```

## Запуск
```
python crosshair_singlefile.py
```

## Сборка EXE (Windows)
Запустить `build.bat` — или выполнить вручную:
```
pyinstaller --onefile --windowed --name "CrosshairOverlay" --add-data "crosshair_settings.json;." crosshair_singlefile.py
```
EXE появится в папке `dist\`.

## Новые возможности

### 🖼 Иконка в трее
- Двойной клик — показать/скрыть панель настроек
- Правый клик — контекстное меню:
  - Показать панель
  - Toggle click-through
  - Открыть профили
  - Настроить горячие клавиши
  - Выход

### ⌨ Настройка горячих клавиш
- Открыть: кнопка «Горячие клавиши» в панели или через трей
- Можно назначить любые клавиши для:
  - Показать/скрыть панель
  - Включить/выключить click-through
  - Выход

### 💾 Профили прицела
- Сохранить текущие настройки прицела под любым именем
- Загрузить сохранённый профиль
- Удалить профиль
- Активный профиль помечается звёздочкой ★

### 🎯 Типы прицела
| Тип       | Описание                   |
|-----------|----------------------------|
| cross     | Классический крест         |
| dot       | Точка                      |
| circle    | Окружность                 |
| cross+dot | Крест с точкой в центре    |
| x         | X-образный прицел          |

### ⚙ Параметры
- Размер, толщина, зазор
- Размер точки
- Прозрачность
- Сдвиг X/Y от центра экрана
- Цвет прицела и обводки
- Обводка (outline)
- T-shape (убирает верхнюю линию)
